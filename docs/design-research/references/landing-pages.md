# Landing pages

Nimbus currently has no marketing route: `/` redirects to `/files`. These references apply only if a public developer-facing landing page becomes a product requirement.

## Dub design system

- **Source platform:** Refero
- **Product/design:** Dub design system
- **Direct URL:** https://styles.refero.design/style/b0d80806-b724-4ed1-a1d1-074edd3c9bc9
- **UI category:** SaaS landing page and product preview
- **Platform:** Web
- **What works well:** The product UI itself acts as proof, a restrained neutral system keeps the hierarchy clear, and one accent color identifies primary actions.
- **What should not be copied:** Dub's brand typography, dotted textures, floating partner cards, and exact product-mockup composition.
- **Reusable principle:** Demonstrate the product with authentic workflow evidence instead of generic cloud imagery.
- **Nimbus application:** Pair the API-first promise with one real console capture, one upload architecture explanation, and concise developer proof such as OpenAPI/SDK/CLI examples.
- **Rights/status:** Public reference only; no assets or styles copied.

## Supahero library

- **Source platform:** Supahero
- **Product/design:** Curated hero-section library
- **Direct URL:** https://supahero.io/
- **UI category:** Hero and marketing layout
- **Platform:** Web
- **What works well:** A broad public collection makes it easy to compare proposition, headline, CTA, and proof placement.
- **What should not be copied:** Any single site's layout, imagery, copy, or brand treatment; the collection includes many unrelated visual styles.
- **Reusable principle:** A hero should communicate one audience, one outcome, one primary action, and one proof artifact.
- **Nimbus application:** Target developers, state the storage-platform outcome, make documentation/self-hosting the primary path, and show a genuine console/API artifact.
- **Rights/status:** Public browsing only; linked works retain their own rights.

## Direction

Use the **editorial developer workspace** direction only on a future public landing page. Keep the authenticated console's compact operational language separate so marketing hierarchy never degrades routine task density.
