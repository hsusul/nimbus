# Navigation

## PostHog design system

- **Source platform:** Refero
- **Product/design:** PostHog design system
- **Direct URL:** https://styles.refero.design/style/56cd3725-3ff0-459e-894d-5da58d1fc549
- **UI category:** App shell, sidebar, technical workspace
- **Platform:** Web
- **What works well:** Compact entries, small radii, hairline borders, and limited accent use create a legible technical workspace.
- **What should not be copied:** The distinctive corkboard/paper metaphor, proprietary typography, or exact color system.
- **Reusable principle:** In an operational console, stable geometry and clear active state matter more than visual novelty.
- **Nimbus application:** Retain the current sidebar/topbar footprint and cobalt active state; refine hierarchy through copy and spacing rather than dramatic restyling.
- **Rights/status:** Public reference only.

## Folder collection

- **Source platform:** Layers
- **Product/design:** Folder design collection
- **Direct URL:** https://layers.to/search/folder
- **UI category:** Folder hierarchy, file manager, app shell
- **Platform:** Web and mobile concepts
- **What works well:** The collection surfaces repeated patterns around hierarchy, compact metadata, file/folder recognition, and structured workspace shells.
- **What should not be copied:** Individual community posts, icons, or unverified UI kits; popularity is not usability evidence.
- **Reusable principle:** File navigation should make location, hierarchy, and the next valid action immediately recognizable.
- **Nimbus application:** Preserve one breadcrumb/current-folder hierarchy and make move/drop destinations explicit.
- **Rights/status:** Public collection page; individual creator rights not verified.

## Nimbus-specific navigation decision

Files, Search, Jobs, and Trash map to real capabilities. Recent, Shared, and Favorites currently appear as disabled “Soon” entries. Primary navigation should describe today's product; consider removing or de-emphasizing those roadmap items until backed by routes and contracts.
