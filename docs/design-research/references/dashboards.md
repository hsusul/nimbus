# Dashboards

Nimbus's `/files` route should remain the working home surface. Research supports adding status clarity around the file list, not replacing it with an analytics dashboard.

## File Management Dashboard — Storage & File Share UI

- **Source platform:** Dribbble
- **Product/design:** Mohamed Gamal's file-management dashboard
- **Direct URL:** https://dribbble.com/shots/26717585-File-Management-Dashboard-Storage-File-Share-UI
- **UI category:** File dashboard, storage, activity, table
- **Platform:** Web
- **What works well:** It combines storage visibility, recent-file access, activity metadata, and an organized file table.
- **What should not be copied:** The exact dark-sidebar/light-canvas composition, color palette, or speculative activity modules.
- **Reusable principle:** System status should be visible without competing with the primary file-management task.
- **Nimbus application:** Strengthen the sidebar storage summary and optionally add meaningful access/finalization metadata to rows; keep the file list dominant.
- **Rights/status:** Visual inspiration only; no reuse license identified.

## Cloud Storage Dashboard

- **Source platform:** Dribbble
- **Product/design:** Product SAAS / Cansaas cloud-storage dashboard
- **Direct URL:** https://dribbble.com/shots/26613948-Cloud-Storage-Dashboard
- **UI category:** Storage health and system feedback
- **Platform:** Web
- **What works well:** Used, total, and free capacity are explicit, turning quota from a surprise into a visible system condition.
- **What should not be copied:** A large analytics section that pushes files below the fold or category colors without functional meaning.
- **Reusable principle:** Capacity feedback should be quantitative, timely, and actionable.
- **Nimbus application:** Show used/total consistently and introduce a text-labeled warning threshold before uploads fail.
- **Rights/status:** Visual inspiration only; no reuse license identified.

## Cloudy UI kit

- **Source platform:** Behance
- **Product/design:** Cloudy — Cloud File Storage Dashboard UI Kit by Robbi Darwis
- **Direct URL:** https://www.behance.net/gallery/217245913/Cloudy-Cloud-File-Storage-Dashboard-UI-Kit
- **UI category:** Responsive file-management system
- **Platform:** Web/responsive
- **What works well:** Its category list treats onboarding, dashboard, file management, search, notifications, restore/delete, and administration as connected flows.
- **What should not be copied:** The 112-screen visual kit, vector assets, components, or invented features unsupported by Nimbus.
- **Reusable principle:** Evaluate interface completeness as a state-and-flow matrix, not as a handful of hero screens.
- **Nimbus application:** Use its category coverage as a checklist for existing Files/Search/Jobs/Trash/Sharing flows.
- **Rights/status:** Paid asset under a stated Standard Commercial License; not purchased or reused.
